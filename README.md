# Rabia Ramzan Portfolio

A responsive, single-page portfolio built with React, TanStack Start, Vite, and Tailwind CSS.

## Development

You need a current version of [Node.js](https://nodejs.org/) or [Bun](https://bun.sh/).

```sh
git clone <your-repository-url>
cd rabia_portfolio
bun install
bun run dev
```

## Quality checks

```sh
bun run test
bun run build
```
